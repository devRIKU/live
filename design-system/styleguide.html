Design system

Lively

A token system for an assistant chat interface. Structural layer from the Apple Human Interface Guidelines; three effects borrowed from brands that actually solved this problem — Sarvam's flow spectrum and Mistral's pixel construction.

Architecture

Three layers, one direction of dependency. Component CSS may only reference semantic and component tokens — a primitive name appearing in a component stylesheet is a bug.

1 · PRIMITIVE
--p-neutral-900 · --s-4 · --r-fixed-lg
--t-body · --e-3 · --d-slow
raw values, no meaning
2 · SEMANTIC
--text-primary · --fill-2 · --separator
--accent · --spec-hi · --flow-spectrum
role names, theme-aware
3 · COMPONENT
--composer-radius · --composer-chip-radius · --popover-shadow · --send-size
bindings for one part of the interface

Flow spectrum

Sarvam's continuous blue-to-orange transition. Extracted from their published --gradient-* tokens, not recalled.

#393cc1 · brand blue #6a88e2 · indigo-500 #bed2ff · periwinkle #eaaf1c · gold #d5650f · brand orange
reserved The spectrum appears only in a flow state — generating, streaming, syncing. It is never a surface fill, never a card background, never decoration. If the spectrum is on screen, something is moving. If nothing is moving, the spectrum must not be on screen. .u-flow-text · .u-flow-bar

Motion

Entrance uses ease-out. Movement on screen uses ease-in-out. Never ease-in on a UI element — it delays the first movement, which is the exact moment the user is watching.

07

Specular rim

A fake lighter border that reads as light catching the edge of glass. It is a true 1px gradient ring — light source at the top-left, falloff through edge-on, refraction into shadow at the bottom-right, then a bounce of light off the far corner.

Why it is a mask, not a border

A gradient border can be built with background-clip — face on padding-box, edge on border-box. But that needs an opaque face to mask the edge layer. Every glass surface here uses backdrop-filter, so the edge bleeds through the interior. A mask punches the content box out instead, so the ring is only ever the ring.

gradient border over glass — bleeds
blurred edge
masked ring over glass — clean
clean edge
utility .u-specular paints the ring. data-focused="true" swaps it for --spec-ring-focus, so focus re-lights the rim instead of drawing a halo around the control. --spec-ring-on-accent is the variant for saturated fills, where the rim reads as a lit sphere.
08

Pixel motif

Mistral's emblem is a chunky pixel sprite in monochrome with exactly one accent pixel. The LF monogram uses the same construction — a pixel-matrix LF in ink with a single pixel in the brand orange.

one pixel Exactly one accent pixel per emblem. Ambient grid texture stays at or below 0.06 opacity — a pixel grid at full strength is a texture; at 0.05 it is a material.

10

Rules

The checks that keep the system from eroding.

tokenSemantic names only in component CSS. A primitive name in a component stylesheet is a bug.
tokenNo colour invented at the call site. If a role is missing, add it to tokens.css first.
reservedThe flow spectrum appears only in a flow state. It is a signal, never a surface.
one pixelAt most one accent pixel per pixel emblem.
textureAmbient texture — pixel grid, aurora, arch grid — stays at or below 0.06 opacity when it is decoration.
shapeRadii come from fixed, capsule or concentric only. Never an arbitrary value.
motionOnly transform and opacity animate. UI animation stays under 300ms.
motionUnder prefers-reduced-motion, remove movement but keep comprehension — the streaming caret stays visible and solid.
themeLight and dark are the same tokens with different values. No component branches on theme.
a11yEscape closes popovers, sliders are arrow-key operable, focus is always visible, touch targets at least 44×44.
